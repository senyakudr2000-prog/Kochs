# Mobile Perf (Fabric 1.21.11)

Требуется: Fabric Loader, Fabric API, Sodium 0.8.x для 1.21.11.

Этап 1: страница "Mobile Perf" в настройках Sodium, отсечение далёких частиц и сущностей.
Этап 2 (в планах): кеш чанков на диск и показ на заданной дальности.

## Сборка без ПК
1. Создай пустой репозиторий на GitHub и загрузи в него все файлы (включая папку .github).
2. Вкладка Actions -> build -> Run workflow (или любой push).
3. Когда сборка зелёная, открой её и скачай артефакт mobileperf-jar.
4. Положи mobileperf-0.1.0.jar (не -sources) в папку mods игры.
